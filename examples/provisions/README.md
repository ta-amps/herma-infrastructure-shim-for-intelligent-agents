# Example Provisions & Atomic Noun/Verb Context

Each `examples/provisions/*.json` file conforms to `herma.schemas.Provision` (`extra="forbid"`) and carries verified `metadata_tags.fabric_governance` for Layer-1 lens parity across local and cloud-synced callers, while `examples/provisions/context/*.json` holds atomic `herma.schemas.ContextEntry` records (`noun`, `verb`, `detail`) seeded into Herma's `system_builtin` context database:

- `PROV-DIRECT-NOUN-VERB-SCHEMA.json` -- `action: "respond_directly"` rule that answers natural-language **Tasks (`verbs` on the wire) and Task Objects (`nouns` on the wire)** and canonical noun/verb schema lookups directly in the caller's protocol (`/v1/chat/completions`, `/v1/responses`, `/v1/messages`, `/v1/dry-run`, `/api/preview`) with zero upstream LLM tokens, attaching `noun:tessera.lease_fence` and `verb:tessera.claim` from the context database.
- `PROV-TESSERA-FENCING.json` -- Tier-1 keyword/path/tool + Tier-2 semantic trigger (`action: "shim_context"`) that shims monotonic lease fencing rules, authoritative URIs, and `context_refs` (`noun:tessera.lease_fence`, `verb:tessera.claim`).
- `PROV-RISK-REVIEW-NON-ACCUSATORY.json` -- Tier-1 keyword/path + Tier-2 semantic trigger enforcing non-accusatory risk indicators and `SYNTHETIC` bundle checks.
- `PROV-HARNESS-FEEDS-GUIDE.json` -- Tier-1 keyword/path + Tier-2 semantic trigger shimming structured context on **Agent Harness Research Feeds** (encapsulating `Feed` Task Objects, `HarnessTax` token overhead, and receipt-backed benchmarks across **Harness Square / Harness2**, **OpenCode**, **Pi**, and **Muse Code**).
- `PROV-LORA-MEMORY-ROUTING.json` -- Tier-1 keyword/path + Tier-2 semantic trigger shimming the decision rule for **Prompt Shimming vs LoRAs as Parametric Memory vs Frontier Passthrough** (`Muse Spark Open`, `Muse Glimmer 30B QLoRA`, `Muse Spark 1.3`, `Muse Wonder 1.0`).
- `PROV-NGO-HUMAN-BOUNDARY.json` -- Tier-3 micromodel classifier trigger enforcing `human_only` crisis boundaries and `drafter != reviewer`.
- `PROV-EDGE-ORIGIN-LOCKDOWN.json` -- Tier-1 keyword/path trigger enforcing `x-edge-auth` (`EDGE_SECRET`), cookie stripping, HSTS, and CSP on Cloudflare Workers.
- `context/CONTEXT-TESSERA-NOUNS-VERBS.json` -- Builtin atomic `noun`, `verb`, and `detail` entries (`noun:tessera.lease_fence`, `verb:tessera.claim`, `detail:herma.shim_budget`, `noun:harness.feed`, `detail:herma.lora_vs_shim`) queryable via `GET /v1/context` and protected under `caller_scope = "system_builtin"`.
